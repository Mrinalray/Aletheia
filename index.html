THE INTEGRITY LAYER

HOW ALETHEIA + BLOCKCHAIN WORK

AI and blockchain answer two different questions. AI asks "does this media appear fake or AI-generated?" Blockchain asks "does this media still match the version that was originally registered?"

⇪
STEP 01
Upload Media

You upload an image, video, or other supported file to Aletheia, the same way as always.

→
◈
STEP 02
AI Analysis

Aletheia's existing detection pipeline analyzes the media and reaches its real / AI-generated / inconclusive verdict — on its own, independent of anything blockchain-related.

→
#
STEP 03
Generate Fingerprint

A SHA-256 cryptographic hash — a unique fingerprint — is generated from the exact bytes of the analyzed file.

→
⛓
STEP 04
Blockchain Registration

If you choose to register, that fingerprint and a few small verification details are recorded on-chain. The media file itself is never uploaded to the blockchain — only the fingerprint.

→
⌕
STEP 05
Future Verification

Later, anyone can submit that same file to Aletheia. It's hashed again and compared against the fingerprint stored on-chain.

→
✓
STEP 06
Integrity Result

Matching hashes confirm the file is identical to the registered version. A mismatch means the file has changed — it does not, by itself, mean the media is fake.

AI ANSWERS "Does this media appear fake or AI-generated?"
BLOCKCHAIN ANSWERS "Does this media match the previously registered version?"
